# PDFCraft for iPad

Native iPadOS application for PDF viewing,
Apple Pencil annotations, and Autodesk
Construction Cloud integration.

## Technology
- SwiftUI
- PDFKit
- UIKit / Apple Pencil
- Autodesk Platform Services (APS)

## Development
Native iPadOS builds will use GitHub Actions
with macOS and Xcode.

## Status
Initial project setup.
